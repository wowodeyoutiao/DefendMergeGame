## 胜利结算界面只显示脚本文字、无图标（bug 修复，8d75292）
- 超哥反馈：胜利结算界面全是脚本文字，没有图标展示。
- 根因：`showVictory` 把整段 HTML（rewardsHtml + 文案）传给 `showModal`，但 `showModal`（app.js:4300）用 `modalBody.textContent = body` 渲染，HTML 被当纯文本原样显示 → 用户看到 `<div class="victory-reward">…<img>…` 这类源码，图标不解析。
- 既定型模式：项目中 `showLevelBriefing`（2766）、武将界面顶栏（4773）都在 `showModal` 之后用 `modalBody.innerHTML =` 覆盖 body 区；`showVictory` 漏了这一行。
- 修复：在 `showModal("胜利结算", body, victoryActions);` 之后加 `modalBody.innerHTML = body;`（app.js:4723 附近）。CSS（theme.css:2652-2690 `.reward-frame`/`.victory-reward`/`.vf-1~8`）本来齐全，无需改样式。
- 验证：node --check ✅ / static-scan ✅ / regression-dom 90 项 ✅；服务 5173 = 200。
- 提交：`8d75292`（仅 app.js，+1/−0）。

### 经验（防再犯）
- 任何把 HTML 字符串传给 `showModal` 的调用点，必须在 `showModal` 之后用 `modalBody.innerHTML = body` 覆盖，否则 HTML 被 `textContent` 当源码显示。建议后续把该覆盖逻辑直接内化进 `showModal`（加一个 `options.html=true` 选项）以根除此类遗漏。
