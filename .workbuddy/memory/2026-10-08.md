# 2026-10-08 工作日志

## 步数返步机制改版（超哥定制）
- 普通棋子合并返步从「固定 +1」改为**按超出 3 个的部分累加**：4→+1、5→+2、6→+3、7→+4、8+→+5；触发概率沿用 `(合并数-3)*0.2` 封顶 100%（仍保留"几率"趣味，但合并越大返还越多，给玩家追求与反馈）。
- 不在 `eliminateMatches` 内直接 `state.steps +=`，改为回合结束后由 `resolveBoardAfterMove` 统一累加，并触发两条反馈：
  1. 居中飘字 `#stepRefundToast`（新增元素）：`本次合成消除了X个元素，获得Y点步数返还！`（X=最大合并簇数量，Y=累计返还步数，宝箱返步也走同一条）。
  2. 飘字开始淡出时（1300ms）对 HUD 步数 `#stepsText` 做 `rollStepsText` 数字滚动（easeOutCubic，700ms）+ 放大高亮（`steps-rolling`）。
- 涉及文件：`app.js`（eliminateMatches 返回 refundEvents / resolveBoardAfterMove 累计 / 新增 applyStepRefund、rollStepsText）、`index.html`（#stepRefundToast）、`styles.css`（`.step-refund-toast` + `#stepsText.steps-rolling`）。
- 验证：`node --check` / static-scan / regression-dom(90项) 全过；服务探活 200。未 git commit（超哥靠 IDE 变更列表核对）。
