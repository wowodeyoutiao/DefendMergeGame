## 二、致命阻断（P0）

### F1 · 「下一关」路径架空整套差异化系统

- **玩家视角问题**：顺着「下一关」一路打，怪物特性、卡牌加权、本关机制预告全部停在第 1 关配置，列甲/群涌/闪避/铁壁等全新机制在常规流程里**几乎永不出现**。
- **玩家场景**：第 1 关看了预告、打了列甲教学，之后每关点「下一关」，永远只遇到带「列」徽章的怪；第 3 关该来的列甲（−60%）、第 5 关群涌、第 7 关闪避、第 8 关铁壁全都不来；三选一卡牌也永远偏向男法师。
- **根因（已核验）**：
  - 结算「下一关」按钮绑定 `nextLevel()`（`app.js:4635`）。
  - `nextLevel()`（`app.js:6524`）只做 `state.level += 1; resetGame(false);`，**既不重设 `state.levelModifier`、也不调 `showLevelBriefing()`**。
  - `state.levelModifier` 仅在 `showLevelBriefing`（`app.js:2683`）赋值，而该函数只在 `startLevelFromHome`（`app.js:2677`）调用。`resetGame` 完全不碰该字段。
  - 下游 `spawnMonster` 读 `state.levelModifier.monsterTrait`（`app.js:3780`）、`pickWeightedCards` 读 `state.levelModifier.cardBias`（`app.js:4422`）→ 从第 1 关起**永久滞留**。
- **针对性修复（建议立即做，风险极低）**：在 `nextLevel()` 里推进关卡后，重设修正并弹预告：
  ```js
  function nextLevel() {
    state.level += 1;
    state.selectedLevel = state.level;
    resetGame(false);
    showBattle();          // 确保进入战斗界面（当前缺，点完「下一关」可能卡在结算残留态）
    showLevelBriefing();   // 内部会 state.levelModifier = LEVEL_MODIFIERS[state.level] || null，并弹预告
  }
  ```
  > 说明：`showLevelBriefing` 有 `briefingShownForLevel` 守卫，不同关会重弹、同关不重复弹，符合预期。`completeLevelToHome()`（6530）回到首页后下次走 `startLevelFromHome` 会重设，无需额外处理。

## 三、明显影响留存（P1）

### F2 · 增益列/险恶列染色永不显示

- **玩家视角问题**：第 5/6 关预告里「险恶列/增益列」的棋盘染色，进战斗后完全看不到。
- **玩家场景**：看完第 5 关预告「第 3 列是险恶列，怪物更快」，进场后整块棋盘没有任何彩色列，不知道哪列危险、该把武将放哪列。
- **根因（已核验）**：`styles.css:603` `.lane-layer { display: none }`，仅 `.lane-layer.active`（609）才显示；但 JS 从不给 `#laneLayer` 加 `active` 类（`renderLanes` app.js 只在初始化创建 `.lane` 子节点，且 2907 行读 `state.levelModifier.board` 时值可能还是上一关）。叠加 `renderLanes` 仅初始化时调一次（6666），换关不重渲染。
- **针对性修复**：
  1. `showBattle()` 或每关进入时给 `#laneLayer` 加 `active` 类（或把 `.lane-layer` 默认改为显示，由 `.lane` 透明兜底）；
  2. `renderLanes()` 在每次进战斗/换关时调用，且此时 `state.levelModifier` 已由 `showLevelBriefing` 设好。

### F3 · 移动端 tipText 全部不可见

- **玩家视角问题**：手机玩家看不到任何「为什么不能换」「漏怪扣血」「合成出特殊棋子」等反馈，也看不到基础规则文字。
- **玩家场景**：手机上斜向交换棋子无提示、漏怪不知为何掉血、合成葫芦只看到飘字无解释。
- **根因**：`tipText` 只在桌面 `side-panel`（`index.html:240`），而 `styles.css:1666` 在 `@media (max-width:760px)` 下 `display:none` 隐藏整个侧栏；`app.js` 仍大量向它写反馈（tryMove 2981、startWave 3711、moveMonsters 漏怪 3994、eliminateMatches 3260 等）。
- **针对性修复**：移动端把 `tipText` 改为**战斗内顶部 toast**（新建一个独立于 side-panel 的 `#battleToast` 元素，桌面/移动共用），所有 `setTip` 写入改走该元素。

## 四、打磨项（P2，按影响排序）

### F4 · 卡牌 bias 键名拼写不一致（已核验）
- 根因：`CARD_DEFINITIONS` id 为 `war-cry`/`rapid-fire`（连字符，app.js:840/847），但 `LEVEL_MODIFIERS` 写成 `warCry`/`rapidFire`（驼峰，503/504/507/508），`pickWeightedCards` 用 `bias[card.id]` 比对 → 这两张卡权重恒为 1。
- 修复：把 `LEVEL_MODIFIERS` 的 `warCry`→`war-cry`、`rapidFire`→`rapid-fire`，与 card id 对齐（主 counter 卡 columnMaster/rowMaster/areaMaster/execution 拼写已一致，不受影响）。

### F5 · 铁壁关推荐「破甲卡」但卡池无破甲机制
- 根因：`MONSTER_TRAITS.ironwall.desc`（491）与 `showLevelBriefing` 兜底 `counterName`（2696）写「破甲卡」，`CARD_DEFINITIONS` 却无任何降韧性机制；`execution`（斩首）只对高血量 +35%，对韧性无效。
- 修复（二选一）：① 把第 8 关推荐语改为「高 tier 武将 / 列阵精通（单点）」，去掉「破甲」误导；② 给某张卡加 `reduceResilience` 字段并在 `resolveWarriorAttack` 接入。建议先做①（快、零新系统），②留作后续 build 深度。

### F6 · 步数归零自动开战
- 根因：`app.js:3355` `if (state.steps <= 0) startWave();` 在 `resolveBoardAfterMove` 末尾无条件触发，无「即将出怪」提示。
- 修复：步数归零时先弹轻提示「准备出怪！」+ 0.6s 缓冲，再 `startWave`；移动端用 F3 的 toast。

### F7 · 移动端学不到三武将攻击形态
- 根因：`renderLegend`（1849 + index.html:241）只在桌面 side-panel；移动端隐藏，战斗内无内置教学。
- 修复：把三武将「同列/同行/范围」攻击形态说明搬进**首遇关卡预告**或战斗内常驻小图例（复用 F3 的战斗内 UI）。

### F8 · 选关界面无机制/难度预期
- 根因：`home-stage-title` 仅显示关名+序号（index.html:72-91），`LEVEL_MODIFIERS` 信息未在主页呈现。
- 修复：主页选关时，若 `LEVEL_MODIFIERS[selectedLevel]` 有特性，关卡标题下加一行小字徽章（如「列甲·推荐法师」），让玩家进关前就能决策是否先去养成。

### F9 · 「放增益列」指引无落点提示
- 根因：合成落点由系统决定（`targetIndex` 3242），玩家无法精确控制；叠加 F2 染色缺失，信息断层。
- 修复：依赖 F2 修好列染色后，预告里把「把对应武将放在增益列」改为可选提示（不强求），或把增益列做成「该列合成的武将自动 +1 射程」的被动说明，降低操作负担。

### F10 · 倍速悬浮按钮易误触
- 根因：`styles.css:1343` `.speed-float { left:8px; top:50% }` 悬浮在棋盘左缘，战斗滑动手指易碰到切换 1x/2x。
- 修复：给按钮加 `pointer-events` 隔离区 + 点击确认（长按 0.3s 才生效），或下移到左缘更外侧、远离棋盘交互区。

### F11 · 特殊棋子用途无教学
- 根因：葫芦/宝箱/陷阱/地雷只在消除后由 `tipText` 提示（3217-3237），移动端不可见（F3）。
- 修复：并入 F3 的统一 toast 通道 + 首次出现时加一行图例说明。

### F12 · 预告只弹一次、可跳过、无重看
- 根因：`showLevelBriefing` 用 `briefingShownForLevel` 守卫（2684），任意「开始守城」点击即关，无重看入口；叠加 F1 后常规流程甚至不再触发。
- 修复：F1 修好后预告会随关卡重弹；另在战斗内 HUD 常驻一个「本关特性」小图标（点击重看预告），解决手滑跳过问题。
