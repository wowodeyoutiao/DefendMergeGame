# 合战守格小游戏软件适配验证

## 验证范围

本次使用 Microsoft Edge Chromium 的 Playwright 无头环境，对当前本地工程进行布局回归检查。测试覆盖主界面、战斗、成长、强化、升星、装备、包裹、合成、选卡、商店、任务、主角成长和结算界面。

测试脚本：`tools/audit-responsive.mjs`

## 历史网页检查结果（不代表小游戏真机验收）

- 221 个视图与尺寸组合通过。
- 无面板横向裁切、内容横向溢出、资源加载失败或页面脚本错误。
- 手机短屏的棋盘格保持至少约28px，底部战斗操作栏和主界面导航不被裁掉。
- 棋子已移除浏览器按钮默认内边距，图标不会因小尺寸格子被压缩成细条。
- 主界面货币、体力和经验信息在窄屏保持单行显示；完整经验值通过标题和无障碍标签保留。
- 装备页六个部位预留固定高度，窄屏下装备名称不再逐字竖排，空槽和已穿戴槽位保持同一版式。
- 历史检查仅模拟 `safe-area-inset-*`；它不包含微信右上角胶囊，不能证明小游戏内主要操作未被宿主遮挡。

## 微信胶囊避让（2026-09-23）

- 两张同机截图表明，参考游戏的操作栏位于胶囊下方；本工程原先从屏幕顶部开始放置资源与操作，侵入了宿主区域。截图像素不等同于 CSS 像素，不以截图分辨率硬编码 UI 尺寸。
- `safe-area.js` 在首屏之前读取 `wx.getMenuButtonBoundingClientRect()` 和 `wx.getWindowInfo()`（兼容旧版 `getSystemInfoSync()`）。顶部取刘海安全区、胶囊底边加 8 CSS px 的较大值，底部保留手势区域；不把两个顶部安全区重复相加。
- 主界面、战斗、弹窗共用顶部避让量和剩余可用高度。宿主设备的怪物接近区优先压缩，棋盘格仍保持正方形；极短屏剩余高度小于 460 CSS px 时允许纵向滚动，不能宣称所有尺寸均无滚动。
- 页面 resize、微信窗口 resize、页面恢复可见时重新读取。识别到小游戏但胶囊接口不可用时，暂用至少 96 CSS px 顶部保留量；这只是兜底，不保证覆盖所有未知宿主布局。
- 没有微信接口的 WebView / 转换容器，需要由宿主调用 `window.GameSafeArea.setMetrics({ windowWidth, windowHeight, safeArea, menuButton, isMiniGame: true })`。尺寸与矩形使用同一逻辑坐标，不传未经换算的截图物理像素。若内容窗口已在屏幕中下移，额外传入 `viewportOffsetTop`（内容窗口顶边在矩形坐标系内的位置），避免重复避让。`setMetrics(null)` 恢复自动读取。
- 包装页也可使用 `?host=wechat` 显式声明宿主，在桥接数据到达前启用兜底。普通浏览器不默认空出胶囊区域。
- `?host-preview=1` 是网页布局验证入口：绘制不可点击的模拟胶囊（顶部 56、底部 88 CSS px），内容自 96 CSS px 以下开始。仅用于布局对比，不伪装成真机结果。
- 数值与桥接回归：`node tools/test-safe-area.cjs`。当前微信真机效果仍需用包含本次修改的发布包复测，旧包不会随网页源码自动更新。
- 本次网页胶囊预览复测：320×568、375×667、390×844、430×932 的战斗顶部均从 96 CSS px 开始，底栏未越出窗口，棋盘保持正方形。320×568 的主页“开始守城”底边 504，底部导航顶边 516；商店面板范围为 104～560。390×844 商店面板范围为 104～836。均为浏览器布局测量，不是微信真机结论。

## 兼容边界

- 游戏当前仍以竖屏手机为主体验方向，建议发布配置锁定竖屏。
- 844×390 横屏已做可用性兼容：棋盘、格子和操作按钮不发生横向裁切，但整体内容高度大于短横屏，会产生垂直滚动。这是为了保留可操作的棋盘触控尺寸和战斗 HUD，不等同于横屏满屏适配。
- 本次验证不是 iOS WebKit 真机、Android WebView 真机、微信小游戏容器或抖音小游戏容器认证；接入平台 SDK 后仍需在对应容器及刘海机型上做最终验收。

## 复测命令

在工程根目录执行：

```powershell
$env:NODE_PATH='C:\Users\Admin\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\node_modules'
& 'C:\Users\Admin\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' tools/audit-responsive.mjs --output tmp/responsive-audit
```

脚本默认访问 `http://127.0.0.1:5173/`，需要先启动：

```powershell
node tools/serve.mjs --port 5173
```
