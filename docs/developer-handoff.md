## 启动试玩

安装 Node.js（建议22 LTS或更新版本），解压完整工程，在包含 `index.html` 的目录运行：

```powershell
node tools/serve.mjs --port 5173
```

浏览器打开 `http://127.0.0.1:5173/?v=20260921-output-cleanup`。无需安装 npm 依赖，也不需要访问原始 D 盘素材目录。

若5173端口被占用，可改为 `--port 5174`，浏览器地址同步改为5174。内置服务仅监听本机回环地址；这个本地地址不是可跨设备分享的公网链接。

每次源码调整后，都需要重新生成全量工程压缩包，并同步提供新的本机试玩链接。

## 最近调整

- 装备成长弹窗固定高度，常驻预留两排可穿戴装备空间；超出列表范围时内部滚动。
- 攻击力、暴击值、命中值为固定数值，只有攻速为百分比。
- 普攻对每个目标独立判定命中与暴击；怪物通过闪避值、韧性值对抗。
- 暴击率：`clamp((max(0, 暴击值 - 韧性值) * 0.005 + 4) / 100, 0, 1)`。
- 未命中时在怪物头顶飘出“闪避”；真实暴击在伤害数字前追加“暴击”美术字。普通高伤害、大招、地雷和全屏卡牌不误标为暴击。
- 战斗飘字兼顾窄屏边路显示，使用工程内位图资源并预加载。
- 关卡内容池规划为 900 关；每 5 关切换章节地图，7 个章节完成后循环使用，关卡解锁本身不设置硬上限。
- 主角技能与武将突破数值评估见 `docs/hero-growth.md` 和 `docs/warrior-skill-evaluation.md`；当前武将品质6常态伤害倍率约为男法师1.22、男战士1.28、女祭司1.35。
- 波次规则为第 1～3 关 3 波、第 4 关 4 波、第 5 关 5 波、第 6 关 6 波、第 7 关及以后 7 波；每一关最后一波固定生成 Boss。
- 怪物从 `stand`、`walk`、`attack` 三套 GIF 中按当前状态切换；跨过棋盘底边后先播放约 0.45 秒攻击动作，再移除并扣除防线生命。

## 开发注意

- 进度保存在当前浏览器、当前站点的本地存储中，不随源码压缩包共享；更换浏览器、域名或端口会使用不同存档。
- `sword` 对应男法师同列攻击，`fan` 对应男战士同行攻击，`rock` 对应女祭司范围攻击。保留这些存档键，避免误换已有装备归属。
- 武将局外突破品质与棋盘合成等级是独立字段。金色独立模型暂未制作，旧存档金色品质显示红色模型兜底，属性不降级。
- 其余对抗初值暂为基础命中100、暴击0、怪物闪避100、韧性0；各关成长数值仍需策划确定。命中不足时的闪避效果需使用对抗数值更高的测试怪验证。
- 激励广告仍为本地模拟流程，未接抖音或微信广告 SDK；此工程不是已完成平台适配的发布包。
- 日常运行不需要 Python。重新处理武将资源时才需要 Python、Pillow、NumPy，具体见 `docs/warrior-models.md`。
- Android 构建需要额外安装 SDK/JDK，见 `android/README.md`。签名密钥由接收方自行生成和保管。
- 主流竖屏适配记录见 `docs/responsive-validation.md`；当前工程以竖屏手机为主体验方向，横屏短屏保留可滚动兼容，不宣称已完成微信、抖音容器和 iOS WebKit 真机验证。

```powershell
powershell -ExecutionPolicy Bypass -File tools/package-project.ps1 -SkipApk
```
