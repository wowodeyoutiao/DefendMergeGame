# 关卡难度评估

## 结论

本轮按普通玩家的30天资源与养成进度复核难度。模型中，普通玩家第30天约推进至245关；看满广告玩家约推进至312关。这里的关卡进度是资源和体力模型的期望值，不等同于保证通关。

## 难度曲线

关卡采用两段式曲线：

- 总怪数：`33 × 关卡^0.35`。
- 单怪平均血量：`100 × 关卡^0.72`。
- 第1至20关不增加额外后期倍率。
- 第21关开始，每关增加0.3%血量压力，最高附加1.35倍。
- 普通关最后一波生成1只Boss；Boss血量为本波基础HP乘4，再乘重甲模板1.7。
- 挑战模式额外增加5至10波，血量难度乘1.35，每3波出现2只Boss，保持普通模式和挑战模式的收益差异。

工作簿中的“出怪分钟”只统计生成间隔；实际战斗还包含消除、选卡、控制、尾怪清理和广告，因此不是完整局时长。完整目标仍以平均约3分钟为准。

## 完美防线

完美宝箱要求结算时防线为100%。本轮修正前，Boss每7秒会无条件扣1点防线，导致即使没有漏怪，Boss血量较高的关卡也无法获得完美宝箱。现在Boss狂暴只提供3秒移速压力，防线伤害只来自怪物真实越过棋盘边界，条件与玩家可观察、可操作的行为一致。

建议用真实试玩数据持续观察以下指标：第7、14、20、30关的首次通关率与满血通关率。目标区间为：首次通关率75%/70%/65%/60%，满血率55%/45%/35%/25%。低于目标时优先调整对应章节血量或控制收益；高于目标过多时优先增加Boss血量或怪物构成，不直接增加漏怪伤害。
