# 合战·守格 MVP Demo

这是一个静态可试玩 demo，用来验证消除塔防核心循环。

## 运行

```powershell
node tools/serve.mjs --port 5173
```

然后打开 `http://127.0.0.1:5173/`。

## 当前包含

- 2026-09-08 统一 Q 版皮肤：明亮青绿场景、珊瑚主按钮、分类 Buff 图标与统一弹窗；美术说明见 `docs/art-direction.md`
- 2026-09-08 战斗飘字：接入美术库中的“怪物掉血”位图数字，每次命中都在对应怪物头顶显示动态伤害数字

- Q 版边塞主界面，默认作为游戏首屏，集中展示玩家信息、金币、体力与当前关卡
- 主界面中央提供当前关卡、守城阵容、三档宝箱目标、难度切换与开始守城入口
- 挑战模式：对应普通关卡满血通关后开启，消耗20点体力，每关每日最多3次；波次额外增加5～10波，每3波出现2只Boss，金币与材料按普通模式2.5～3倍结算，并必定掉落普通品质+1～2的装备
- 普通模式三个元宝宝箱奖励为50/100/150元宝；挑战模式独立拥有三个元宝宝箱，奖励为普通模式的3倍（150/300/450元宝），与普通模式的宝箱记录分开保存
- 武将成长页提供突破预览：展示突破后外形、下一品质真实被动技能、装备属性永久保留和突破消耗；成长、打造、商店页面统一顶部返回、货币栏和页签层级，长内容区域支持滚动
- 已完成战力与战斗数值回归：装备、强化、升星会提升战力；攻击力进入实际伤害，攻速进入攻击间隔，命中/闪避与暴击判定均按武将和怪物对抗属性生效
- 顶部资源栏已压缩为一行；关卡支持左右箭头与左右滑动切换，下一关在通关前显示锁定预览
- 主界面按中央关卡焦点重新排版：顶部角色与三种资源保持同一行，中央使用圆形场景缩略图切换关卡，右侧常驻主线快捷任务，三武将阵容、宝箱目标、难度与开始按钮依次向下排列。
- 主界面第二轮美术优化直接接入用户提供的透明 UI 部件图：标题 Logo、左侧任务/背包入口和底部五功能导航使用原图裁切资源；动态货币、关卡、任务进度、宝箱状态及武将养成外形仍由代码实时渲染。
- 新增12步永久主线引导任务，从通关第1关、穿戴首件装备、通关第2关逐步引导至强化、升星、全套装备和首次突破；奖励随难度投放金币、元宝、强化石与升星石。首关首次通关保底掉落一件装备，避免随机掉落阻断任务链。
- 主界面三名武将始终读取各自局外养成品质；任意武将突破后，主页对应位置立即切换到该品质的外形与动作资源。
- 关卡宝箱默认关闭，未达成目标保持锁定；完成关卡后仅解锁对应的通关宝箱
- 底部常驻商店、武将、关卡、成长、包裹 5 个功能入口，为后续局外系统预留
- 主界面与战斗状态联通：开始新关卡扣除 10 点体力，中途返回后可继续当前战局
- 关卡内容池规划为 900 关，前 35 关按 7 个章节轮换地图，每 5 关更换场景；超过内容池后继续循环章节，不在战斗界面显示总关卡数。规则见 `docs/levels-scenes-monsters.md`
- 6x6 满盘开局，交换后按横/竖/斜线 3 连消除，空位从底部自动补满
- 消除男法师、男战士、女祭司可提升对应棋子的局内等级，最高 4 级
- 武将射程随等级成长，范围控制半径同步成长
- 棋盘上方提供 6 格高的怪物进场区，用于体现不同等级射程差异
- 拖拽或点选上下左右相邻棋子换位；非相邻换位不生效、不扣步数，广告提示遵循同一限制
- 4 连起按消除数量获得递增的步数返还概率
- 每次换位后全盘自动检测并连续消除，连锁期间锁定操作
- Boss 波中的普通怪逐只随机选择进场列，只有 Boss 会沿操作期红色预警所标示的固定列进场
- 战斗操作期可观看激励广告获得棋盘提示，每局最多 5 次；广告完成后会扫描真实可行的交换，并发光标注可形成消除的棋子
- 战斗操作期新增“广告洗牌”，每局最多3次；完整看完广告才随机重排全部棋子，不扣步数，保留种类、等级及附加属性。新布局无直接连消且至少有一组合法相邻换位；无法找到可用布局时不播放广告、不消耗次数。
- 只有类型和等级都相同的棋子才能组成消除线，消除后生成高一级棋子
- 没有形成连线时仍完成换位并消耗 1 步；若全盘无其它连线则结束本次操作
- 新增宝箱、陷阱、地雷，并支持消除后在目标格生成高一级棋子
- 操作期 / 出怪期
- 防线 HP、金币、波次
- 怪物移动速度降低为原来的 50%，波次基础血量同步翻倍
- 7 个章节分别配置近战、远程小怪和 Boss；怪物从进场、移动到越过防线分别使用待机、行走、攻击动作资源
- 武将接入白到红6档、每档3职业的独立外形与动作；男战士同行、男法师同列、女祭司范围。外形按局外突破品质同步到成长页、主界面及棋盘，发起攻击才播放攻击动作（被闪避也播放）；资源与构建说明见 `docs/warrior-models.md`
- 武将白到红每次突破解锁一项自动被动：伤害、攻速、多目标增伤、多目标控制、终阶伤害。技能按同列/同行/范围的实际覆盖难度做差异化补偿；多目标效果要求一次实际命中至少2只怪物，控制带独立触发冷却。主角技能按等级解锁，战斗中点击头像手动释放，每局随机生成技能队列；主角只承担全屏伤害、全屏控制和防线恢复。金色武将与新技能暂不开放。
- 加步数、复活、双倍结算的广告模拟
- 局外主角养成：金币升级每级 +1 防线生命，10/20/30/40 级消耗元宝突破，突破后才可继续升级；本轮 MVP 主角上限 40 级，不限制关卡数量。
- 5 个主角技能：裂地重击、幽影禁锢、青风横扫、圣光护城、破阵战鼓。点击头像按解锁顺序轮换，独立 CD，选卡暂停冷却。
- 通关、失败均发放金币与元宝，结算防重复领取；本机保存等级、突破、货币、体力和关卡解锁进度。数值与交互规则见 `docs/hero-growth.md`。
- 武将装备成长：每名武将 6 个部位、7 档品质，胜利掉落装备，包裹支持同品质 5 合 1，整套装备可消耗元宝突破并转为永久属性。详见 `docs/equipment-growth.md`。
- 装备追求节奏：品质前缀为粗制、精良、秘银、星辉、龙魂、神威、天命；每关 68% 掉落，连续 3 次未掉落保底，高品质采用后期低概率分段表。
- 包裹改版：皮革美术、五列装备格、品质/部位筛选，独立5合1材料选择及结果页；支持数量出售和二次确认的批量回收。额外奖励开关待确认后启用，规则见 `docs/equipment-bag.md`。

## 工程打包

`powershell -ExecutionPolicy Bypass -File tools/package-project.ps1` 将源码、全部资源、文档、工具、Android 源码和现有 APK 打包，并逐文件校验 SHA256。不包含历史 ZIP、日志、临时构建、软著输出及本机签名密钥。Android 构建环境见 `android/README.md`；接收方重新构建时会生成自己的测试签名。

仅共享最新工程时添加 `-SkipApk`，避免附带尚未用最新源码重建的旧 APK。包内包含资源对照图；接手说明与本次版本信息见 `docs/developer-handoff.md`。

## 资源交付

所有运行时资源都随工程目录交付，主要目录如下：

- `public/assets/`：战斗背景、棋子、怪物、主角与通用 UI 资源
- `public/assets/warriors/`：武将待机、攻击和技能动作
- `public/assets/monsters/`：各轮怪物动效与静态降级图
- `public/assets/monsters/actions/`：按章节引用的怪物与 Boss 待机、行走、攻击 GIF
- `public/assets/ui/`：卡牌、面板、体力和增益图标
- `public/assets/home/`：主界面导航、任务、军报、货币和宝箱资源
- `public/assets/equipment/`：从 `UI切图/icon武器` 与 `UI切图/icon装备` 筛选的装备部位图标
- `public/assets/ui/equipment/`、`public/assets/ui/character/`：品质底图、角色页背景、装备槽和页签素材
- `public/assets/ui/bag/`：包裹皮革外框、方形品质底图、材料槽、选中标记与合成效果素材
